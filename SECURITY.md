# Security

Cinq runs agents' code and holds the keys to your repositories, so reports are welcome and taken seriously.

**Report a vulnerability privately:** use GitHub's "Report a vulnerability" on this repo's Security tab, or email
alex@altrwork.com. Please don't open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. We aim to reply within 3 working
days and to ship a fix or mitigation within 30 days, and we'll credit you unless you'd rather we didn't.

Supported: the latest published version of `cinq-git`. Cinq deploys into your own Cloudflare account; issues in
Cloudflare itself go to Cloudflare. Known limits of the design (for example, tests have network access) are listed in
the README's Limits section.
